文档元数据核验 — 样式方案对比

以下 5 套方案布局完全相同（顶栏+侧栏+详情，与当前应用一致）， 仅优化了配色、圆角、边框、间距等视觉样式。
选定方案后即可直接应用到正式前端代码。

国企政务门户

参考中国政府网设计语言：蓝白配色、方角窄边、扁平无阴影、信息层级清晰。最正式、最安全的选择。

央企专业办公

参考国家电网/中石油内部OA：深灰蓝顶栏、方正棱角、信息密度高、专业工具感强。适合注重效率的大型央企。

党政纪检严肃

参考纪检监察风格：深红顶栏带权威感、暖灰底色柔和护眼、衬线标题庄重。适合纪检/审计/合规部门。

政务数据看板

参考统计局/发改委数据平台：深藏蓝顶栏、纯白底、极简阴影、数据展示清晰。现代清爽但不过于活泼。

银行金融稳重

参考工商银行/建设银行后台系统：深藏蓝顶栏、灰色系底色、方正稳重。适合金融/投资类国央企。

所有方案共享相同的 DOM 结构和 CSS 类名。 与当前应用的唯一区别在于 CSS 变量（颜色/圆角/阴影/间距），不改变任何布局逻辑。
