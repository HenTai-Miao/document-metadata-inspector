文档元数据核验 · 国央企风格三套

deepseek-v4-pro 出品 — 针对"卡片感太多、不适用国央企"反馈重新设计

设计原则：抛弃浮动卡片式布局，采用结构化分区（表格行 / 面板 / 公文章节）。
配色以政务蓝 + 红色点缀为主，边角方正克制（3-6px 圆角），无渐变、无毛玻璃、无浮夸阴影。
设计参考：中国政府网、国资委信息系统、央企 OA 系统。

方向一：政务门户
方案十 · 政务门户风
表格式检测结果 + 概览统计条 + 顶部标签导航。所见即所得，无卡片累赘感。政务蓝底顶栏，红色竖线标识风险行，适合日常核验操作。
表格化 无卡片 政务蓝
方向二：企业数据看板
方案十一 · 企业数据看板
KPI 统计条 + 左右双栏面板 + 进度条。风险项和通过项左右分列，一眼掌握全局。紧凑高效，适合管理层快速审阅。
数据看板 双栏布局 紧凑高效
方向三：公文简报
方案十二 · 公文简报风
仿政府公文格式：红头标题 + 章节编号 + 宋体标题 + 检测项条目式陈列。最接近体制内阅读习惯，适合生成正式核验报告。
