# Element Plus 国资稳健蓝结果页设计

## 目标与批准依据

本设计把用户已经选定的“Element Plus · 标签导航”页面结构与“国资稳健蓝”主题落实到 Electron 正式结果页。前序五版 Mock 已完成比较，用户明确选择本方案并要求更新前端，因此本文件记录批准后的最终实现边界，不再重新选择版式或主题。

页面的单一任务是：让审计人员在同一页快速定位 11 类问题标签，并沿“问题标签 → 命中值 → 公司组合 → 双方文件”读取完整证据。

## 变更边界

- 只调整 Electron 渲染层的正式结果页 DOM、全局视觉 token、顶栏视觉和相关自动化测试。
- 不改变 Python 比较算法、报告 JSON、共享合同、IPC、目录选择、扫描流程、结果数据模型或元数据明细数据。
- 11 类问题标签、命中值、公司关系、文件名、风险/无风险结论及其顺序保持不变。
- 不引入 Vue 或 Element Plus 运行时依赖。现有桌面端是原生 TypeScript DOM 渲染器，本次使用 Element Plus 的克制层级、间距、圆角与状态表达，避免为纯视觉更新重写技术栈。

## 视觉系统

### 色彩

- 国资深蓝 `#0b315a`：顶栏和最高层级品牌面。
- 主操作蓝 `#174b82`：主按钮、问题关系、焦点和导航选中态。
- 信息蓝 `#2f6fa8`：次级强调与文件证据标记。
- 浅蓝底 `#eaf2f9`：命中值栏、风险标签导航选中态和关系名称底色。
- 页面灰蓝 `#f3f6f8`：结果页背景。
- 中性边框 `#d6e0e9`：卡片、表格分隔和索引边界。
- 风险红 `#c53b43` 与安全绿 `#237a57`：只承担状态语义，不作为大面积背景。

取消当前命中值的黄色/橙色视觉。命中值改为浅蓝底、深蓝标签和中性正文，使页面完全进入国资稳健蓝体系。

### 字体

- 标题与正文：`PingFang SC`、`Microsoft YaHei`、系统无衬线字体栈。
- 文件名和证据原值：现有系统等宽字体栈。
- 层级主要通过字号、间距、边框和背景区分，不依赖大量粗体或装饰。

### 形态

- 控件和卡片以 8–10px 克制圆角为主。
- 阴影只用于必要的层级分离，结果证据卡不使用漂浮式大阴影。
- 页面不使用渐变、玻璃拟态、发光、装饰性图标或无意义动画。

## 页面结构

```text
┌ 国资深蓝顶栏：产品 / 文件夹 / 操作 / 离线状态 ─────────────┐
├ 页面摘要：11 类问题标签 / 风险数 / 无风险数 / 公司关系 ───┤
│ ┌ 问题标签索引 238px ┐  ┌ 右侧完整证据详情 ────────────┐ │
│ │ 创建人检测  有风险 │  │ 问题标签：创建人检测        │ │
│ │ 修改人检测  有风险 │  │ 命中值：李建国              │ │
│ │ 批注人检测  无风险 │  │ 公司 A ↔ 公司 B            │ │
│ │ …共 11 类           │  │ 双方文件                    │ │
│ └────────────────────┘  │ …其余风险与无风险标签        │ │
│                         └──────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

左侧是同页索引，不是隐藏内容的 Tab。右侧仍按固定顺序完整渲染全部 11 类标签，审计人员无需切换或展开即可读取所有证据。索引项可作为页内锚点帮助定位，但不得改变或过滤右侧内容。

## 证据层级

### 有风险标签

1. 标签卡头：完整“问题标签：××检测”、有风险状态、命中值数和公司关系数。
2. 命中值栏：浅蓝底，左侧为“命中值”标签与原始值，右侧显示关系数。
3. 公司关系：三列布局，第一列是“公司 A ↔ 公司 B”，后两列分别列出双方文件。
4. 多个命中值和多个公司关系全部展开，保持现有数据顺序。

### 无风险标签

无风险标签使用与风险标签相同的外层卡片、标题和计数结构，正文明确显示“无风险”和“未发现跨公司相同值”。左侧索引同步标记“无风险”。

## 响应式

- 大于 900px：左侧固定 238px 索引，右侧证据自适应；索引在结果滚动容器内保持可见。
- 560–900px：索引移动到证据上方并以两列排列，右侧证据保持全宽。
- 小于 560px：索引与证据全部单列；公司关系标题独占一行，双方文件随后逐列排列。
- 所有尺寸禁止页面级横向溢出；文件名允许安全换行。

## 标志性元素与自检

本页的标志性元素是“国资蓝问题标签索引轨道”：它把 11 类固定检查项变成可快速扫描的审计目录，同时不隐藏右侧任何证据。这一结构来自文档元数据核验的实际审查流程，不是通用仪表盘侧栏。

自检后删除了大面积风险色、黄色命中值、统计卡片组和装饰性图标。风险红只出现在状态标签，主视觉由深蓝顶栏、浅蓝证据层和清晰的分隔表格承担，符合克制、可信、可审计的国央企桌面工具气质。

## 验收条件

1. 结果页同时渲染 11 个左侧标签索引项和 11 个右侧问题标签卡片。
2. 左侧索引按固定顺序显示风险/无风险，且索引不隐藏、过滤或折叠右侧内容。
3. 创建人、修改人等风险标签继续显示完整命中值、公司组合和双方文件。
4. 所有无风险标签继续显示“0 个命中值 · 0 组公司关系”和“无风险”。
5. 正式结果页不存在黄色或橙色命中值底色，命中值区域使用国资浅蓝体系。
6. 顶栏使用国资深蓝，主按钮、焦点、关系区和文件标记使用同一蓝色体系。
7. 1440×900、1280×800、1024×720、760×760 和 390×844 下没有页面级横向溢出或文字遮挡。
8. 键盘焦点可见，减少动效设置有效，浏览器控制台、页面脚本和资源请求无错误。
9. 现有单元测试、类型检查、格式检查和构建全部通过。
